# Retail Sales Performance Dashboard — Power BI

## Project Overview

Developed an interactive retail sales dashboard using Microsoft Power BI to analyze revenue, profitability, product performance, and sales trends across 2024–2025.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- PostgreSQL (original SQL analysis)

## Key Performance Indicators

- **Total Revenue:** Approximately $3.14 million
- **Total Profit:** Approximately $1.32 million
- **Top Revenue Category:** Home & Office

## Dashboard Features

- Total Revenue and Total Profit KPI cards
- Revenue by Product Category
- Monthly Revenue Trend
- Top 10 Products by Revenue
- Interactive filters for Year, Product Category, and Customer State

## Technical Skills Demonstrated

- Imported and transformed multiple CSV datasets using Power Query.
- Created one-to-many relationships between customers, orders, order_items, and products.
- Developed DAX measures to calculate revenue and product-level profit.
- Built interactive charts and KPI visualizations.
- Implemented slicers for dynamic business analysis.

## Business Insights

The Home & Office category generated the highest total revenue, while Accessories achieved the highest profit margin in the related SQL analysis.

The dashboard allows users to explore sales performance across different years, product categories, and customer locations.

## Dataset

Simulated retail sales data used for educational and portfolio purposes.
