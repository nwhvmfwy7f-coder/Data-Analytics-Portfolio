# Retail Sales SQL Analysis

## Project Overview
This project uses PostgreSQL to analyze a simulated retail sales database containing 10,000 orders. The objective is to identify revenue trends, evaluate customer purchasing behavior, and measure product profitability.

## Tools Used
- PostgreSQL
- DBeaver
- SQL

## Dataset
- 1,500 customers
- 10,000 orders
- 17,440 order items
- 40 products

## SQL Skills Demonstrated
- SELECT and DISTINCT
- INNER JOIN
- GROUP BY and ORDER BY
- COUNT, SUM, and AVG
- DATE_TRUNC
- Revenue calculations
- Profit margin analysis
- Common Table Expressions (CTEs)

## Business Questions
The project investigates total orders, unique customers, revenue, average order value, product performance, regional sales, monthly trends, and profitability.
