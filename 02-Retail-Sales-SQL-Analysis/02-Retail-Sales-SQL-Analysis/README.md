# Retail Sales SQL Analysis

## Project Overview
This project demonstrates my SQL data analysis skills using a simulated retail sales database. The goal is to identify sales trends, evaluate product performance, analyze customer purchasing behavior, and measure profitability.

## Tools Used
- PostgreSQL
- DBeaver
- SQL

## Dataset Overview
- **1,500 Customers**
- **10,000 Orders**
- **17,440 Order Items**
- **40 Products**

## SQL Skills Demonstrated
- SELECT, WHERE, GROUP BY, ORDER BY
- INNER JOIN
- COUNT, SUM, AVG
- DISTINCT
- DATE_TRUNC
- Revenue and Profit Calculations
- Profit Margin Analysis

## Business Questions Analyzed
1. Total number of orders
2. Number of unique customers
3. Total company revenue
4. Average order value
5. Top 10 products by revenue
6. Revenue by product category
7. Revenue by state
8. Top 10 customers by spending
9. Monthly revenue trends
10. Highest-revenue month
11. Most profitable products
12. Highest profit margin by category
